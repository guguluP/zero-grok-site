# Zero Grok extension

Load this folder unpacked in Chrome, Edge or Brave (Manifest V3). Firefox 140+ uses the `background.scripts` fallback.

Version 1.5.0. See `../CHANGELOG.md` for details.

## Layout

| Path | What |
|---|---|
| `background.js` | Service worker: storage, alerts, badge, alarms, update check, selectors refresh, optional-site registration |
| `content/provider-core.js` | Shared runtime for every site: can + panel, SPA remount, countdown, health check, local estimates |
| `content/content.js`, `claude.js`, `chatgpt.js`, `gemini.js` | Built-in providers (only the scraping logic) |
| `content/perplexity.js`, `deepseek.js`, `mistral.js`, `copilot.js`, `metaai.js` | Optional providers. Registered at runtime after the user grants access |
| `content/page-hook.js` | Tiny MAIN-world shim: SPA navigation events, plus Grok's own rate-limit responses |
| `utils/shared.js` | Pure helpers shared by every context (forecast, confidence, parsing, validation) |
| `selectors.json` | Data-only page selectors. A newer copy can be fetched from GitHub; it is validated and never executed |
| `_locales/` | English and Hindi strings |
| `PRIVACY.md` | What is stored and which requests are made |

The packaged ZIP is published to `/downloads/zero-grok.zip` by GitHub Actions on every change under `extension/`. `downloads/version.json` is the feed the optional update checker reads.

Icons and `assets/sounds/can-pop.wav` are generated by `../tools/gen_assets.py`.
